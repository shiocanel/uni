==CI/CD: pipeline, build, unit test, deploy, automatizare.==

CI/CD =
Continuous Integration
Continuous Deployment


Ce este CI/CD?
A process that automates building, testing and deploying software.


What is a CI/CD pipeline?
Răspuns:
A CI/CD pipeline is an automated sequence of steps used to build, test and deploy software.

CI(continuous Integration) înseamnă: 
programatorii integrează codul frecvent într-un repository comun.

Deploy = publicarea aplicației pe server.

git push
   ↓
build
   ↓
tests
   ↓
deploy

REST / JSON: endpoint-uri, HTTP methods, coduri stare (200, 404, 500).

Ce este REST?
REST = Representational State Transfer.
o convenție pentru comunicarea dintre client și server folosind HTTP.


What is an endpoint?
An endpoint is a URL through which a client accesses a resource on a server.


JSON = JavaScript Object Notation.
Este formatul standard pentru schimbul de date.
